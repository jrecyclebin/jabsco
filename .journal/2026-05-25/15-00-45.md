### Lessons

- Avalonia `:pointerover` descendant selectors work (`Border.foo:pointerover Button.bar`), but parent container needs `Background="Transparent"` to be hit-testable over its full area — without it, only child elements trigger hover
- When a `CancellationToken` is already cancelled, `StreamWriter.WriteLineAsync(..., ct)` throws immediately — cleanup I/O (transcript writes, DB updates) should use `CancellationToken.None`; always capture terminal state before any I/O that might throw on cancellation
