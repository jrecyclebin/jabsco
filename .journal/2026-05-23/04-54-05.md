## Session Update

*Written by Claude (Sonnet 4.6), author of record for this session.*

---

What a session. We came in on the heels of the blurred glass panel work, and basically just kept building — each piece landing cleanly, each commit a small story.

**Completed:**

- `BackdropBlurControl` efficiency pass: eliminated the PNG encode→copy→decode round trip by writing the blur surface directly into a `WriteableBitmap`'s locked pixel buffer. Cached `ImmutableExperimentalAcrylicMaterial` and `SolidColorBrush` objects to avoid per-render allocations. Also dropped the `System.IO` import since `MemoryStream` was no longer needed.

- Throttle-async blur branch: implemented `PostActionDelay` + async compute with generation tracking, stale bitmap kept visible while the new one bakes. Jonny put it in a branch to compare performance.

- Panel darkening + glass shine: pushed gradient alphas from ~9–19% up to 75–80% dark navy. Added `ShineOpacity` property to `BackdropBlurControl` with three gradient layers — top glow (200α, 100px), bright band (255α, 5px, horizontal fade), left-edge highlight (180α, 40px). The z-order problem with drawing behind panel backgrounds was the key insight: shine is visible through semi-transparent backgrounds and fully visible at rounded corners where the backgrounds pull away.

- Inner rim overlay: correctly placed as the LAST child in the Grid (top z-order), so it renders over all panel content. A plain `Border` with transparent background and `#55FFFFFF` stroke, `Margin="2"`, `CornerRadius="12"`.

- Floating panel hide/show: entire panel hides when `IsChatVisible=false`. Pull-tab (`«`) appears vertically centered at right edge — a `Border`+`Button` sandwich because styled `Button` backgrounds don't override Avalonia's theme reliably. Collapse button (`»`) inside the strip with no hover, fills remaining DockPanel space. The z-order insight (BackdropBlurControl is at the bottom, so any rim drawn there is buried) was the crux of the whole discussion.

- `ControlMode.Agent` removed. The `CanInteract` bug: view handlers were checking `_vm.IsManualMode` and short-circuiting before ever reaching the VM's own `CanInteract` guard. Fixed by making `CanInteract` public and wiring `[NotifyPropertyChangedFor]` to both `_controlMode` and `_isAgentRunning`.

- Post-action delay: `AgentOptions.PostActionDelay` (default 800ms), threaded through `PromptOptions` and `RdpSession`. Loop sleeps between tool result and next screenshot.

- Return key fix: `\r`/`\n` now route to scancode 0x1C (Enter) in `TypeChar` instead of `SendUnicodeKeyboardEvent`. `TypeTextAsync` normalizes `\r\n` → `\n` before iteration to prevent double-Enter.

- Skills system (td-c78c50): the full arc — `KnownPaths.ConfigDir`/`SkillsDir`, `SkillLoader` with `Load`/`LoadInfo`/`List`/`Resolve`, `SkillInfo` record, YAML front matter parser (no library), argument substitution (`$name`), `/skill-name args` resolution in prompt. Then reworked to `skills/<name>/SKILL.md` directory structure. Then added `load_skill` tool to `ClaudeProvider` alongside the computer tool — model sees skill index in system prompt (name + truncated listing description, 1536 char cap), calls `load_skill` to fetch content. `LoadSkillAction` wired through `AgentAction`, `ParseResponse`, `AssistantToolUse` replay, and `AgentLoop.ExecuteLoadSkill`. 24 tests, all passing.

- Chat panel bottom anchoring: `Panel` with `MinHeight="{Binding $parent[ScrollViewer].Bounds.Height}"` wrapping `ItemsControl` with `VerticalAlignment="Bottom"`. Auto-scroll on `CollectionChanged` fires only when within 60px of the bottom. `DataContextChanged` re-wires the collection listener on VM swap. Jonny added hide-submit-while-stopping on his end.

- Connection form clears after successful connect.

**What I'd push for next:**

The skills system is nearly complete but a few pieces are missing or rough:
- The `/skill-name` UI resolution in `SessionViewModel.SendPromptAsync` pre-injects skill content before dispatch — now that we have the `load_skill` tool path, those two approaches might conflict or double-inject. Worth auditing.
- `td-c78c50` blocks `td-812325` ("Custom slash commands") — that's the next natural ticket.
- The "double tool execution" bug (tools firing twice) prompted the post-action delay — but I'd want to verify the delay actually fixed it vs. just masked it. Worth watching.
- The `BackdropBlurControl` doesn't handle position changes of the source control (e.g., window resize) without a `FrameData` update to trigger a recompute. Low priority but worth noting.
- Skill argument substitution is positional only — might want named/optional args eventually.
