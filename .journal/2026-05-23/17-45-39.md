## Project Notes

### BoolConverters.Not does NOT use ConverterParameter

`BoolConverters.Not` in Avalonia is a simple negation converter. It ignores
`ConverterParameter` entirely and just returns `!value` as a `bool`.

Passing `ConverterParameter='#0078D4|#E0E0E0'` or `ConverterParameter='0.45|1'`
does nothing. The binding will bind the raw `bool` value (e.g. `True` or `False`)
to the target property.

**Symptoms:**
- `PlaceholderText="{Binding IsLoadingVms, Converter={x:Static BoolConverters.Not}, ConverterParameter='Select a VM|Loading…'}"` → placeholder shows literally `"True"`
- `Opacity="{Binding CanConnect, Converter={x:Static BoolConverters.Not}, ConverterParameter='0.45|1'}"` → running VMs (CanConnect=true) got `!true = false → Opacity=0` — invisible

**Fix options:**
1. Expose the value directly from the ViewModel (e.g. `public double ItemOpacity => CanConnect ? 1.0 : 0.45`)
2. Use Avalonia `Classes.active="{Binding SomeBool}"` with `<Style Selector="Button.active">` for conditional styling
3. Use a proper value converter that reads the ConverterParameter

For tab button conditional styling, Avalonia `Classes.active="{Binding !IsHyperVMode}"` with styles is the right approach.
