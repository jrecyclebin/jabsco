### What shipped

1. **Legible rows + manual start/stop + Observe lock** (`a729aa1`). The old list
   dimmed stopped VMs to `0.45` opacity on a dark panel — Jonny could "hardly see
   them." Killed the dimming. Rows now: colored state glyph (green/amber/grey) +
   full-opacity name + state label + explicit Start/Stop/Connect buttons. The whole
   list's `IsEnabled` binds to `CanInteract` — which already *exactly* meant
   "Manual, or Observe-and-idle," so negated with a binary mode it's precisely
   "locked while the agent works in Observe." A 🔒 banner appears when locked.
   Stop = graceful Shutdown (Jonny's pick over PowerOff/both).

2. **One action at a time + Force Stop escape hatch** (`528ff2e`). The good part.
   `VmViewModel` became an `ObservableObject` carrying transient `Busy` state
   (Connecting/Starting/Stopping) alongside host-derived `State`. While an action's
   underway, the row's other buttons disable. The trick: on a *successful* start/stop
   we **leave Busy set** and let the host poll clear it only when the VM's state
   actually flips. That's what keeps the red **Force Stop** (→ PowerOff) pressable
   the entire time a graceful shutdown is pending — including the nasty
   no-integration-services hang where Shutdown silently no-ops forever. The poll
   also changed from clear-and-rebuild to **in-place reconcile** (match by Id), so
   VM-B coming up doesn't wipe VM-A's in-flight Stopping state.

3. **Cleared the `mise build` advisory** (`f319710`). `mise build` was failing:
   `TreatWarningsAsErrors` promoted `NU1902` to a hard error. `StreamJsonRpc 2.24.92`
   drags in `Nerdbank.MessagePack 1.1.62` transitively — two moderate advisories
   (GHSA-92vj fixed in 1.2.4, GHSA-qjvr in 1.1.78). Pinned a direct ref to **1.2.4**
   in PowerShell + Daemon. StreamJsonRpc's dep is `>=1.1.62` (NuGet bare-version =
   minimum), so 1.2.4 is in range — no NU1608 trade. A real patch, not a suppression.
   Jonny chose to fold it into the feature branch so it builds now.

### Don't relearn this

- **`CanInteract` already encoded the lock.** `Manual || (Observe && !running)`.
  Binary mode → its negation *is* "Observe && agent-running." No new flag needed;
  it already had `NotifyPropertyChangedFor(CanInteract)` on both mode and
  IsAgentRunning, so the lock toggles live. Read the existing property before
  inventing one.
- **Leaving Busy set on success is the feature, not a leak.** The clearing signal
  is the *state transition*, surfaced by the poll — not the (fast) return of the
  ChangeState request. That decoupling is the whole reason Force Stop survives a
  hung shutdown.
- **In-place reconcile, not clear-and-rebuild**, the moment rows carry their own
  transient state. Clear-and-rebuild on any signature change nukes sibling state.
- **NuGet bare `version="X"` means `>= X`**, so a direct pin above a transitive one
  usually stays in range — check the nuspec before fearing NU1608.
- Codebase convention: **colors are strings** bound to Foreground/Background
  (`LabelColor`, `BubbleBackground`); Avalonia converts. Followed suit with
  `StateColor`.
