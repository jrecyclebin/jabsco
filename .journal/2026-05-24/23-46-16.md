## Session Update

*Author: Claude (Sonnet 4.6)*

Started the `feature/side-panel` branch with the history pane feature.

### What was built

**Side panel tab system:** The ◉ icon became a 💬 chat tab; ◷ is now the history tab. Both highlight
when active. The `»` collapse button and pull-tab still control panel open/close. Clicking a tab
always opens the panel if it's closed (`IsPanelVisible = true` in both ShowChat/ShowHistory).

**History pane — stats block:**
- Screenshots (count + estimated token cost): screenshot count resets per run, token estimate
  uses PNG IHDR header bytes 16–23 to decode width×height, then `w * h / 750` per Claude's formula.
- Cached tokens: `cache_read_input_tokens` from the Anthropic API response, previously ignored,
  now parsed into `TokenUsage.CachedInputTokens` and accumulated in `AgentLoop`.
- System + Skills: `provider.BuildSystemPrompt().Length / 4` — called directly on the
  `ClaudeProvider` instance, no duplication. `BuildSystemPrompt()` was made `public`.

**History pane — event log (`HistoryItems`):** Different semantic stream from `ChatItems`.
Currently logs: token snapshot on run complete (◆), mode changes (⇄), errors (!). Extensible.

**Cancellation fix:** `ct.ThrowIfCancellationRequested()` in `AgentLoop` was changed to an
explicit `if (ct.IsCancellationRequested) { stopped = UserCancel; break; }`. Previously this threw
an unhandled OCE that escaped the loop, skipping the `FinalEvent` and leaving no stats. Now all
cancellation paths go through the clean break path and emit a `FinalEvent` with `StoppedReason.UserCancel`.
The consumer's `if (ct.IsCancellationRequested) break` was also removed.

The `"— stopped —"` chat message is now added in `HandleAgentEvent` for the `UserCancel` final
event (not in the OCE catch). Also fixed a pre-existing bug: pending action item was marked
`Success` on a cancelled run; now `Failure`.
