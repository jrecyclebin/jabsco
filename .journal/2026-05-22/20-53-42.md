- Added chat item presentation helpers in `ChatItemViewModel`: sender label, metadata text, user-prompt alignment flag, and glass-friendly bubble colors.

- Imported/adapted `BackdropBlurControl` from `rocksdanister/weather` with MIT attribution in `src/Jabsco.Ui/Controls/BackdropBlurControl.cs`.
- First direct Skia surface-snapshot implementation caused the session view to render black. Reworked the control to avoid reading/writing the active render target.
- Second custom draw implementation rendered the panel but looked clear/no-blur. The visible fix was to abandon `ICustomDrawOperation` for the backdrop image path and instead generate a cached, downsampled blurred `Bitmap` from `CurrentFrame`, then draw it through Avalonia's normal `DrawingContext.DrawImage`.
- User confirmed the bitmap fallback finally produced visible blur. Then blur was toned down by changing `DownsampleScale` from `0.08` to `0.18` and `BlurSigma` from `6.0f` to `3.2f`.
- User then made follow-up tweaks locally: chat text sizing, template-level input border styling, and hiding metadata on action items.

**Important outcomes:**
- The rocksdanister control's original active-surface snapshot approach is risky in this app. It can black out the RDP session view because it interacts directly with the live Skia render target.
- A custom draw operation can fail invisibly enough that the XAML gradient still appears, making the panel look "clear" even though the control exists. Normal Avalonia bitmap drawing is more reliable here.
- For the glass panel, the effective recipe is: use `CurrentFrame` as the blur source, map the panel origin relative to `FramebufferControl`, downsample heavily enough to soften detail, blur the downsampled image, cache per frame/bounds/origin, then apply a light material tint over the bitmap.
- Current blur constants after assistant tuning: `DownsampleScale = 0.18`, `BlurSigma = 3.2f`.
